Photographs go in this folder.

The site looks for these three files. Any that are missing simply show an empty
mount with the filename on it, so the page still works while you gather images.

couple.jpg   A couple portrait. Portrait orientation, 4:5 crops best.
candid.jpg   A candid wedding moment. Portrait orientation.
social.jpg   The thumbnail Facebook shows when the link is shared.
             Landscape, 1200 x 630 pixels.

Export each at about 1600 pixels on the long edge and keep them under 400 KB so
the page stays quick on mobile data. Use lowercase filenames exactly as spelled
above — most web hosts treat Couple.jpg and couple.jpg as different files.

To add more photographs somewhere else on the site, copy one of the <figure
class="frame"> blocks in index.html and point its <img src> at your new file.
